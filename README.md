## 📌 Overview

This project analyzes a multi-table e-commerce database (orders, customers, products, payments) to answer real business questions using **pure SQL** — no external BI tool. It demonstrates query design, performance tuning, and the ability to turn raw data into decision-ready insights.

**Business questions answered:**
- Who are the top 10 customers by lifetime value?
- Which products drive the most repeat purchases?
- What is month-over-month revenue growth?
- Where do customers drop off in the order funnel?
